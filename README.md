# طلبات فريج بن عاقول وجست بنز

تطبيق ويب لطلب الأكل من مطعمي **فريج بن عاقول** و**جست بنز** في البحرين.

- قائمة مصوّرة للعلامتين مع سلة واختيار الفرع (9 فروع) أو التوصيل
- الدفع بتحويل آيبان أو BenefitPay مع رفع صورة الإيصال
- متابعة حالة الطلب للزبون
- لوحة الفرع (`#board`) لتأكيد التحويلات وتحريك الطلبات، مع إعدادات الدفع والأسعار والصور

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages على فرع `main`.

## ملاحظة
النسخة الحالية تحفظ الطلبات في متصفح الجهاز (localStorage)، فلوحة الفرع ترى الطلبات المرسلة من نفس الجهاز فقط.
ربط قاعدة بيانات مشتركة (مثل Supabase) هو الخطوة التالية لاستقبال طلبات الزبائن من جوالاتهم.
